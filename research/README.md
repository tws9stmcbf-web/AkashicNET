## Evidence Framework

Research should be classified where appropriate as:

- **Established evidence**
- **Emerging evidence**
- **Working hypothesis**
- **Speculative**
- **Historical / cultural context**

## Source Standards

Whenever possible:

1. Prefer primary research.
2. Identify peer-reviewed sources.
3. Link to the original publication.
4. Record publication details.
5. Distinguish correlation from causation.
6. Record important limitations.
7. Note conflicting evidence.
8. Avoid overstating conclusions.
