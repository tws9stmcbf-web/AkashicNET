# Interactive Living Library Map

This route overlays semantic controls on a responsive illustrative asset.

## Boundaries

- The artwork is explicitly an ecological metaphor, not scientific evidence.
- BQ001 remains `UNRESOLVED`.
- Search Garden language describes a proposed anonymous aggregate inquiry layer; it does not collect or publish raw queries.
- Hotspots link only to existing public routes or governed homepage sections.
- The fallback destination list preserves keyboard and screen-reader access.
- Touch activation reveals context before navigation.

## Validation checklist

1. Confirm every internal route resolves.
2. Test keyboard focus order and visible focus styling.
3. Test VoiceOver/TalkBack labels and the fallback list.
4. Verify 200% zoom and 320 px layout.
5. Verify reduced-motion behavior.
6. Confirm the image digest and asset manifest before release.
