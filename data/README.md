# 📊 Data

A dedicated space for datasets, structured observations and research data associated with the Noetic Sciences Toolkit.

## 🎯 Purpose

Data should be documented separately from interpretation so that observations can be examined, reproduced and analysed independently.

## 🧪 Possible Data Types

- Experimental measurements
- Survey data
- Citizen-science observations
- N-of-1 observations
- Behavioural measures
- Physiological measurements
- Environmental measurements
- Structured qualitative observations

## 🔐 Privacy

Do not upload personally identifiable, confidential or sensitive personal data.

When human participants are involved, appropriate consent, anonymisation and ethical safeguards should be considered before data are published.

## 📋 Data Documentation

Where appropriate, datasets should include:

- Dataset description
- Collection date
- Collection method
- Variables and units
- Sample size
- Inclusion/exclusion criteria
- Known limitations
- Relevant research protocol
- Data dictionary
- Source or provenance

## 🔄 Reproducibility

Where possible, provide enough information for another researcher to understand how the data were collected and processed.

Original observations should be distinguished from derived or transformed data.

## ⚖️ Interpretation

Data are observations, not conclusions.

The Toolkit should distinguish:

**Data → Analysis → Interpretation → Conclusion**

Unexpected or contradictory results should be retained where ethically and practically possible.
