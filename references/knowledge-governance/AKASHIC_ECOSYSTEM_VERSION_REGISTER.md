## Record fields and maintenance

For each discovered framework, retain stable ID, name, role, exact source version, public display version, phase or series identifier where applicable, current/proposed/historical status, source location, inspected commit and access date, supersession history and next verification action.

For linked posts, retain stable source/post ID, source URL or repository pointer, original publication date when known, access date, material actually examined, framework version used at assessment time, topics, precise claims, evidence status, alternatives, uncertainty and separately typed BQ connections. Prevent duplicate counts for URLs, underlying works and repeated citations.

Update through dated follow-ups; never infer a new release from data quantity, a public article or repeated mentions. Unknown values remain unknown until verified.
