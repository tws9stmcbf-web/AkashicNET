# Akashic Library — provenance and permission investigation

## Methodology

This review is intentionally limited to provenance and rights evidence that can be identified without opening, downloading, extracting, OCR'ing, or otherwise reproducing PDF content.

The investigation reviewed only:

- repository metadata already recorded for the three PDFs
- canonical Google Drive references already stored in the Toolkit
- publicly discoverable metadata and author/source labels already present in repository records
- public web lookup attempts for the exact filenames and canonical Drive references from this environment

No PDF file was opened, copied, extracted, or redistributed. No item was changed from `INDEX_ONLY`.

## Important constraint

A public source page or a visible filename alone does not establish permission for reuse. The repository defaults to conservative handling unless a source page or licence note clearly states reuse terms that permit import or redistribution.
