# AkashicOMNI v0.4.2 · PRE-ALPHA

19 September 2026. Compatible clarification patch to v0.4.0, authorised by the project owner in this conversation.

## What changed and why

The embodied-intelligence pathway needed a clearer distinction between comparison, bodily awareness and wisdom. v0.4.2 describes bodily awareness as a potential contributor to wise judgement when interpreted through reflection, evidence, ethics and consequences. This is a reflective principle, not a validated scientific formula. It does not infer that illness produces genius or wisdom.

The existing assessment method now explicitly asks for claim type, source location and actual access, alternatives, missing information, and a proportionate compassionate action. Biographical case labels now say “Biographical context / source account” to accommodate testimony without presenting all sources as independently verified. Source access is distinct from evidence strength and reuse rights. The proposed claim-record and independent-comparison capability stays in the unreleased v0.5.0 draft.

## Version and historical integrity

The owner selected v0.4.2. v0.4.1 was discussed as a possible intermediate patch but was not released; no historical release is invented. Patch numbers count releases, not edits or features. This release combines the two refinement groups proposed in the conversation.

All thirteen perspectives, eight comparative cases and source links are retained. Prior version anchors and dated assessments remain intact. Earlier assessments are not automatically recalculated. Images labelled v0.4.0 remain historical illustrations; generated likenesses and symbolic imagery are not documentary evidence. The current release object supplies version, anchor, date and shared guidance to the Site and repository mirror.

## Boundaries and verification

No AkashicNET product release, Big Question status or maturity, accepted canonical edge, model-support record, privacy, rights or evidence-promotion gate changes. This is not new primary research or independent scientific review. Existing biographies are not claimed to have been independently reverified in this patch.

The publication workflow verifies matching shared guidance, retained perspectives/cases/anchors and a successful Site build before deployment. GitHub sync is reviewed against its exact commit. Deployment and merge status are reported in the completion message rather than fabricated in this note.
