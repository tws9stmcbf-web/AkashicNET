# Anchor evidence contract v0.1.6

Issue #217 defines the audit record required before Batch 4.

The fixture is synthetic only. It contains three anchor records, zero relationship candidates, and zero edges. Every anchor carries typed endpoints, public-safe provenance, an independence key, extraction method and version, the reviewed public metadata field, a reviewer explanation, and an immutable input digest.

Direct anchors remain limited to explicit identifiers, exact full titles, and explicit citations. Corroborating anchors must be distinct in type, value, evidentiary basis, and independence. Generic themes, representation counts, reverse edges, graph proximity, and prior graph links cannot qualify.

Automated truth inference, acceptance, evidence/rights/identity promotion, private Drive metadata, and circular confidence remain prohibited.
